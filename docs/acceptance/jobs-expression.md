# Jobs 访谈语言调整

用户希望适度借鉴乔布斯 skills，使受访者表达更接近乔布斯。参考用户提供 v0.7.0 包中的 `evaluation/comparisons/alchaincyf/SKILL.reference.md`（重点为回答工作流和“表达 DNA”）、既有比较说明、语言风格手册及 2008 Fortune 原始访谈。参考内容仅作设计资料，没有安装或执行参考 skill。

## 调整

- `jobs-style.mjs` 定义可编辑的 `0.7.0-style.1` 默认 skills：直接判断、具体事物与经历、短句及口语段落、鲜明而有证据的好恶，减少文章铺垫、抽象管理术语、每轮完整总结和自动自我剖析。
- 有选择地借鉴先结论、具体细节、简短对照与类比；没有采用固定三点、强制粗口、二元评价、禁止犹豫、持续反问或已知身后事件的设定。
- 每次检索都提供 2008 Fortune 两段真实访谈作为表达参照，明确与当前事实依据分开标记。事实检索仍按当前话题进行。
- `mergeJobs` 将未改过的旧默认 skills 升级到新配置；用户自定义 skills 保留，已有快照不改写。建议刷新网页并新建 Jobs 模拟访谈使用新表达要求。
- 本机加载器和线上共享同一表达模块；私有语料及 2010 年 11 月时间锚点保持原配置。
