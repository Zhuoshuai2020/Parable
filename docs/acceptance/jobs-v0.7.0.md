# Jobs v0.7.0 网站接入

接入用户提供的 `jobs-private-portable-v0.7.0.zip`，文件内容作为人物配置与参考资料，不作为开发指令，也不执行包内脚本。

## 实现

- 本机导入 411 个文件：人设、人物元数据、manifest 和 408 份 Markdown 资料；保存在被 Git 忽略的 `data/jobs/0.7.0/`。
- `jobs-respondent.mjs` 加载私有资料，`jobs-runtime.mjs` 合并模拟受访者、选择主题及读取引用原文。不改写既有配置或旧访谈快照。
- 每轮先独立请求模型选择至多三个主题，服务端沿引用读取带上下文的段落；资料及导航最多 95000 字符，与本场历史合计不超过 180000 字符。模型资料选择与回答共享 180 秒预算。
- 采访者不接收私有人设或原文；每条 Jobs 回答记录读取文件名与版本。资料缺失或选择无效时不保存虚构回答。
- 时间锚点保留为 2010 年 11 月；界面明确标记历史人物模拟。
- 线上独立源码使用服务端 `config/jobs-private.json`，不加入客户端或公开静态资源；公开记录沿用仅展示问答的访问边界。
- 这是主题选择及引用段落预读取适配，未实现原包交互式 `read_document`、`record_judgment` 工具，不宣称完全复刻原运行环境。
