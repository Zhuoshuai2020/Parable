## 当前行为

- 公开、免登录访问；不要求使用 Codex、ChatGPT 或 GitHub 账号。
- 访谈问答和记录列表公开，任何访客均可查看与导出；开场前明确显示“提问与回答将公开”。
- 继续回答、生成和结束访谈仅限创建者浏览器；编辑 Agent 配置仅影响自己的新访谈。
- 浏览器使用 HttpOnly 随机 Cookie，服务端只保存其哈希归属。清除 Cookie 或更换设备会失去写入权限，但仍可公开查看。
- 公开问答不包含私有人设、Skills 或后台诊断。模型密钥仅保存在站点 Secret。
- 模型请求有有限重试和分类错误提示；默认全站每日最多 200 次生成尝试（北京时间日期），通过服务端环境变量调整。
