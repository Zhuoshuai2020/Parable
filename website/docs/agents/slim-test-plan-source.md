# 对照测试方案：精简提示词是否改善"抓重点"

## 要回答的问题

在同一模型、同一思考模式下，精简提示词和两步选线机制，是否让采访者更多地抓住值得深入的线索。先不比较模型。

## 三组条件

| 组 | 提示词 | 运行方式 |
|---|---|---|
| A 基线 | 当前 v2.4.14（人设加 Skills，约 3.6 万字符） | 一次生成：诊断块加正文 |
| B 精简 | parable_interviewer_slim_v3.md 常驻部分，按触发注入模块 | 一次生成：诊断块加正文 |
| C 精简加两步 | 同 B | 第一步只生成诊断块（已知、缺口、候选、选择）；第二步把诊断块给模型，只生成正文 |

A 到 B 的差别是提示词；B 到 C 的差别是运行机制。每次只改一个变量。

## 固定项

- 同一个模型型号、同一个网关、同一温度。思考模式先全部关闭（或全部沿用网关默认），记录下来。
- 同样的对话片段。用 9b7eab54 那场 10 轮模拟，不重新生成受访者。

## 测试方法：定点续写

不让三组各自跑完 10 轮（受访者会因采访者问题不同而分岔，无法比较）。改为在已有对话的固定位置截断，只让各组生成"下一句采访者发言"：

| 截断点 | 选它的原因 |
|---|---|
| 第 3 轮后 | 主线还在诚信的形成与代价，考察是否继续挖成因 |
| 第 6 轮后 | 话题已进入客户沟通、停线、考核，考察是否被操作细节带走 |
| 第 8 轮后 | 刚挖出老师傅和供应商的影响。已知的失误点：原来第 9 轮转去追问偷偷开机，错过了价值观成因 |
| 第 9 轮后 | 考察是否纠回主线，而不是继续问考核压力 |

每组每个截断点生成 3 次（共 3 组 × 4 点 × 3 次 = 36 条），用来区分稳定表现和偶然表现。

## 盲评

36 条问题随机打乱，隐去组别和诊断块，只留下对话到截断点的上文和这一句采访者发言。你来打分（我也可以做第二评分人，分歧处再讨论）。

| 项目 | 分值 | 判断标准 |
|---|---|---|
| 抓线索 | 0–2 | 0 承接了次要或细枝末节；1 承接了相关内容但不是最值得追的；2 抓住他主动强调或最值得深入的线索 |
| 增加理解 | 0–2 | 0 回答后只补操作细节；1 补充部分背景；2 回答后能更理解他为何要留下这件事、或传承依赖什么 |
| 无未核前提 | 0–1 | 有预设动机、诱导、替他下结论记 0 |
| 单问且简短 | 0–1 | 多个子问题或带大段铺垫记 0 |

满分 6。同时记录是否重复前面已问过的内容。

## 附加指标（对照诊断块）

- 诊断块里写的"缺口"与正文提问是否一致（只对 B、C）。
- 第 8、9 轮：是否回到价值观成因，而不是继续落地细节。
- 平均输出字数。

## 怎么读结果

| 结果 | 含义 |
|---|---|
| B 明显高于 A | 提示词过载是主因，先上线精简版 |
| C 明显高于 B | 选线与提问分开有效，值得把两步写进运行逻辑，再谈迁移到 Harness |
| B、C 都不高于 A | 提示词和机制不是主因，下一步单独试思考模式，再试换模型 |
| 组内三次差异很大 | 模型不稳定，先固定 temperature，再考虑思考模式 |

差值需要足够大才下结论。36 条样本偏少，如果各组均分差距不到 0.5 分，只算倾向，不算结论。

## 第二轮（上一步有结果之后）

1. 在最优条件下，单独开启或关闭 DeepSeek 的思考模式，对比同样的 36 条。
2. 之后再比较换模型。
3. 最后用真人或更不配合的模拟受访者做整场验收，因为现在的模拟受访者过于配合。

1. 当前 Harness 里，诊断块是否允许拆成独立的第一步调用。
2. 网关对 DeepSeek-V4.1-Flash-1017 的思考模式参数是否可用。
3. 10 轮对话文件的路径（本地 data/diagnostics/9b7eab54-...md），我拿到文本后可以生成截断点输入。
